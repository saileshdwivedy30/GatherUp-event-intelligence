## 🚀 How to Set Up Your Development Branch
Since `dev` starts empty, follow these steps to reuse existing work:
1. Clone the repository
2. Create your own development branch from `sailesh_dev`
3. Work in your branch and merge to `dev` when your code is fully tested.

🛠 Summary: How Everything Works
1. `prod` (default for deployment) – Final production-ready code.
2. `dev` (default for development) – Only stable, fully working features go here.
3. `<your_name>_dev` – Contains your latest in progress work.
4. Once features are fully tested, `<your_name>_dev` → `dev`.
5. Once dev is completely stable, merge `dev` → `prod`.
